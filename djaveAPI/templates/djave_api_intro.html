Welcome to the API

It's quite sane.

It uses basic authentication. You can get your very own "API Key username" and "API Key password" under "Settings" when you're logged in.

The API speaks JSON.

You can read and write any important object on demand using good old fashioned GET and POST requests.

You can subscribe to webhooks and we'll let you know when any important object changes in any way. Webhooks are configured under "Settings" when you're logged in.
